Engineered a mission-critical laser marking automation solution for the Ford Sakarya Factory by reverse-engineering proprietary production protocols to synchronize real-time vehicle data with the manufacturing process. Built on a hybrid C++ and C#.Net architecture, the system orchestrates the precise operation of the laser unit and peripheral electromechanical components, delivering a high-stability solution that has operated continuously on the production line for years with zero downtime. (2017)
