Engineered an interactive educational robotics platform designed to democratize AI and programming concepts for beginners, supported by the TUBITAK 1501 R&D program. The system features a versatile dual-mode coding environment (Scratch and standard languages) integrated with hardware sensors (camera, microphone) for multimodal human-robot interaction, plus a modular AI interface for sentiment analysis, object tracking, and image recognition. (2020-2021)
