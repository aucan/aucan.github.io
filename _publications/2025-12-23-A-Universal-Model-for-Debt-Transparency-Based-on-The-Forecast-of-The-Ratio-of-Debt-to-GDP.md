Debt transparency is a critical global issue, especially for countries that face difficulties in reporting public debt reliably. This study develops a universal prediction model for estimating the debt-to-GDP ratio of PIIGS countries using machine learning methods (Support Vector Regression, XGBoost, Random Forest, Ridge and Lasso Regression) on quarterly data from 2000-2021, achieving R² values of up to 99.9% with the Random Forest and XGBoost models.
